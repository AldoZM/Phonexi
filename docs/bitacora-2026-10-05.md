## 1. La plantilla de entrevista en la captura con `-cli`

En las mock interviews se pide resolver el problema con esta estructura, la de
*Cracking the Coding Interview*:

```
# Notes
# Questions
# Approaches
# Complexity Analysis
# Edge Cases
# Code
```

Se consideró añadir `# Debugging` al final y se descartó: el libro no la trae.

### Qué pide cada sección

- **Notes** — 2 o 3 viñetas con las restricciones del enunciado que cambian la
  solución (tamaño de entrada, si viene ordenada, duplicados, rango de valores).
- **Questions** — 2 o 3 preguntas de aclaración para el entrevistador.
- **Approaches** — dos viñetas: `- Brute force:` en una línea con su
  complejidad, y `- Optimal:` en una o dos líneas con la idea clave como
  `==frase clave==`. Antes el prompt prohibía la fuerza bruta; en esta
  plantilla sí va, porque es la progresión que el entrevistador espera oír.
- **Complexity Analysis** — tiempo y espacio de la óptima, con el porqué.
- **Edge Cases** — de 3 a 5 viñetas cortas.
- **Code** — solo la óptima, sin docstrings ni ejemplos de uso.

Los encabezados van siempre en inglés; el texto bajo ellos sigue el idioma de
la pregunta. Una pregunta conceptual capturada (Kafka, HTTPS) no usa la
plantilla y sigue con la respuesta corta.

### Por qué solo en `-cli`

- **El API se queda con el formato corto.** Groq corta la salida en 900 tokens
  y seis secciones más el código no caben con holgura. Gemini comparte el mismo
  camino en `processor.py`, así que tampoco cambia.
- **La voz se queda igual.** En voz llegan preguntas sueltas y seguimientos;
  seis secciones por cada una sería demasiado para leer en plena conversación.
  Pulir el modo voz queda para otra sesión.

### Cómo quedó en el código

Los dos caminos ya estaban separados, así que el cambio fue chico:

- `config.py` partió `_SHARED_RULES` en `_LANGUAGE_RULE`, `_CODING_RULE` (el
  formato corto de siempre), `_CODING_RULE_CLI` (la plantilla) y el resto de las
  reglas compartidas. `PROMPT_CAPTURE` y `PROMPT_VOICE` quedaron con el mismo
  texto exacto que tenían; solo se armaron con las piezas nuevas.
- Nuevo `PROMPT_CAPTURE_CLI`, que `system_prompt()` en `engines/base.py`
  devuelve para las capturas de agy y Claude Code.
- Pruebas que fijan los seis encabezados en orden, las etiquetas de Approaches,
  que el API y la voz no reciban la plantilla, y que todas las reglas
  compartidas sigan presentes también en `PROMPT_CAPTURE_CLI`.

- **El fallo intermitente de Tk empeoró.** "Can't find a usable tk.tcl" en
  `test_ui.py` ya existía (3 de 8 corridas en septiembre), pero ahora a veces

  Ya estaba anotado y volvió a pasar: usar la herramienta de escritura.
- **Mostrar el popup desde un script** exige llamar a `show()` desde otro hilo
  con el hilo principal ya dentro de `mainloop()`; si no, se cuelga.
